# Travel 主题验证

本文是供人工评审的中文同步版本，英文 [../08-validation.md](../08-validation.md) 为规范文本。

## 1. 验证门禁

主题依次通过以下门禁：

1. 仓库与几何审计。
2. 概念拆分与几何家族声明。
3. 批量资产审计与清单就绪。
4. 几何优先构建。
5. 应用皮肤。
6. 视觉、交互、响应式与回归验证。
7. 清单/检查点校准。

前一项必需门禁未完成时，后一项 MUST NOT 开始。

## 2. 实现前就绪

修改应用代码前确认：

- 主题 ID 与批准概念无歧义。
- 已指定几何家族与参考。
- 已分离共享值、家族值、皮肤值和建议例外。
- 每个概念必需资产角色为 `READY` 或有理由的 `NOT_REQUIRED`。
- 没有必需角色处于 `MISSING`、`UNSAFE` 或实质性 `UNCLEAR`。
- 每个几何或排版例外已记录并获批。

如果门禁失败，实现 MUST 停止。MUST NOT 使用 CSS 发明或无关结构装饰，让资产集合看起来完整。

## 3. 几何验证

在相同舞台尺寸下，同时对比实现、批准概念与所选几何参考。

MUST 记录 viewport、设备像素比、locale、主题、Atlas/Globe、选中条目/国家、Timeline 年份/mode、camera rotation/zoom 与 reduced-motion 状态。固定相机比较必须通过现有支持的控制或另行批准的测试 fixture 暂停自动旋转；MUST NOT 编造 debug URL，也不得把移动截图当作匹配基线。证据记录应包含浏览器名称/版本及 console/network 错误。

- Header Composition Group MUST 保持内部关系。
- 工具栏 MUST 保持相对 Brand 定位。
- 共享功能边界、顺序、点击区和排版令牌 MUST 匹配。
- Atlas 几何、裁切材质、国家点击路径与标记 MUST 通过同一套 zoom/scope 变换栈保持配准。世界缩放和共享国家聚焦 X/Y scale 下，标记盒 MUST 维持稳定视觉尺寸。
- 布局覆盖 MUST 与已声明校正或批准例外一致。
- 栅格溢出 MUST NOT 改变语义盒。

使用浏览器计算几何与截图，不要只依赖记忆或源码声明。

## 4. 视觉与资产验证

依据清单验证背景适配、alpha、裁切、安全区、材质裁切、标记艺术、图例、缩放、时间线、明信片和可选环境资产。实现 MUST NOT 包含未批准的地图框、面板、边线、阴影盒或替代艺术。

运行时映射、适配规则、状态或例外发生变化时，清单 MUST 更新。

## 5. 交互与内容验证

验证：

- 主题切换、持久化、回退，以及切回每个现有主题。
- 英文/中文文本增长和可见运行时标签。
- 地图加载、边界/轮廓、`0.75` 到 `2.75` 的世界缩放、放置预览与标记选择。
- 国家选择高亮、键盘激活、Explore、聚焦国家几何/材质/条目筛选、返回世界/Escape，以及进入 Globe 或 Owner Edit 时重置 scope。
- Timeline 筛选与国家筛选正确叠加，不泄漏 scope 外标记，也不保留已隐藏条目的选中明信片。
- 时间线上一项/下一项/选择行为与边界状态。
- Timeline v2 用户滚动、滚轮、点击、上一年/下一年和方向键移动必须是一次连续位移，不得出现第二次 snap 或 focused-year 校正。
- 原生 `scrollend` 与 `140 ms` fallback 对同一 scroll sequence 只能 settle 一次；由滚动产生的 focused-year 变化 MUST NOT 触发外部对齐 effect。
- 明信片选择、关闭、照片顺序、竖图处理、标签页、图注、元数据、剪贴簿/画廊和灯箱键盘行为。
- 只读边界：没有编辑/上传/认证控件或修改端点。未来编辑功能需要另行限定范围的测试。
- 焦点、禁用、悬停、选中和减少动态效果状态。

视觉皮肤 MUST NOT 改变这些行为。

## 6. 响应式验证

验证批准的桌面视口、窄桌面/平板视口和当前移动端行为。几何家族移动 SHOULD 以协调组为单位。报告已知移动端限制，不要发明每主题独立的移动构图。MUST 区分实际测试过的桌面 Chrome、macOS Safari、移动 Chrome 与 iOS Safari 和仅源码推断；未测试浏览器 MUST 标记为 `NOT TESTED`。覆盖 WebGL 失败/fallback、横竖屏变化、字体解析与 reduced motion。对高发光材质和 Three.js 铜/毛毡材质记录旋转/拖动帧耗时与内存证据。

视觉 `READY` 与浏览器 PASS 不代表再分发权利。公开交付 MUST 核实清单中的权利/来源字段，并将公开安全证据与私人凭据、旅行记录、照片和日志分开。

## 7. 回归与仓库检查

Globe 工作还要分析自动旋转与拖动。确认只有一个 RAF、rotation 位于 renderer 本地、无逐帧 React render、sphere path 每帧生成零次、启用的 land/country/graticule 每类几何每帧最多生成一条 path、纹理 image 元素稳定，以及静态 halo/atmosphere/rim 位于旋转地理之外。至少对比一个强发光主题和一个 antique 主题，检查 filter/compositing 回归。

运行仓库当前检查，通常为：

```bash
npm run lint
npm run build
git diff --check
git status --short
```

现有主题 MUST 在行为和视觉上保持稳定。最终差异 MUST 检查是否意外修改后端、API、schema、migration、存储、内容、生成文件或无关资产。未实际执行的浏览器或交互检查不得声称已完成。

## 8. 检查点记录

交接前：

- 校准清单与实际运行时引用。
- 记录几何家族和批准例外。
- 识别确认未使用、重复或拒绝的资产，但不删除有歧义的原始文件。
- 记录未解决的架构或视觉债务。
- 规范发生变化时确认中英文文档一致。

新的会话 SHOULD 能仅凭仓库、批准概念、所选几何参考和清单继续工作，而不依赖隐藏对话历史。
