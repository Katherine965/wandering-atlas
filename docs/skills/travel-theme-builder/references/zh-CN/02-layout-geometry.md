# Travel 布局几何

本文是供人工评审的中文同步版本，英文 [../02-layout-geometry.md](../02-layout-geometry.md) 为规范文本。

## 1. 几何层级

1. **共享产品几何（Shared product geometry）** 定义不变的产品关系和功能边界。
2. **几何参考（Geometry reference）** 是经过测量和批准的构图，用于建立可复用的**几何家族（Geometry family）**。
3. **主题皮肤（Theme skin）** 装饰继承的盒子，不移动它们。

每个新主题 MUST 在应用皮肤前选择共享几何和一个具名家族。Deep Sea 是 `standard-atlas` 家族的首个参考。

## 2. 坐标系统

- 桌面舞台 MUST 保持 `16:9`。
- 共享地图坐标空间 MUST 保持 `1672 x 941`；除非另有独立范围的核心变更同时更新投影、逆投影、标记和所有依赖层。
- 几何 SHOULD 使用舞台相对百分比和 `cqw` 表达，而不是视口像素。
- 浏览器测量 MUST 使用舞台局部坐标，并在最终级联、变换和容器尺寸生效后采集。
- Atlas 几何、材质与标记坐标 MUST 共享同一套 zoom/scope 变换栈。世界缩放与共享国家聚焦 scope MUST 保持等比，标记盒也 MUST 在 X/Y 方向等量反向缩放；主题 MUST NOT 增加独立变换数学。

## 3. 共享产品几何

以下是冻结的产品关系，不是每个主题的选择：

| 角色 | 共享值或规则 |
| --- | --- |
| 舞台 | `16:9`；裁切并隔离 |
| 地图坐标 | 共享 `1672 x 941` viewBox 与投影 |
| 最小控件点击区 | `2.25cqw` |
| 工具栏顺序 | Atlas/Globe、语言、Mark a Place、Begin a Journey、Open the Archive |
| 工具栏对齐 | 单行、单一垂直基线 |
| 工具栏控件高度 | `4.5cqw` |
| 视图控件宽度 | 每个 `12.3cqw` |
| 语言组宽度 | `7.4cqw` |
| 主操作宽度 | 每个 `13.25cqw` |
| 工具栏组间距 | `0.2cqw`；内部按钮间距 `0` |
| Atlas 缩放 | 中心锚定；`0.75` 到 `2.75`，步长 `.25`；默认 `1` |
| 国家 scope 控件 | `14cqw x 3.5cqw`、top `52%`、right `1.6%`；Cyber 镜像到 left `1.6%` |
| Timeline v2 root | 居中；width `69.5cqw`、height `16.8cqw`、bottom `-3.25%` |
| Timeline v2 frame | `59.5cqw x 16.8cqw`；功能 viewport `39.5cqw`；year spacing `9.2cqw` |
| Timeline v2 控件 | `3cqw` 箭头、`2cqw` 间距；固定选择装饰位于 frame 中心 |
| 运行时层级 | 背景低于地图；控件高于地图/旧化层；明信片高于地图册控件 |

功能边界、文本区域、点击区、焦点几何和同级对齐 MUST 使用这些共享值。栅格艺术 MAY 在其内部溢出或缩放。

## 4. 页头构图组

Header Composition Group MUST 先解决内部关系，再定位到舞台。

`standard-atlas` 使用以下参考关系：

| 组内关系 | 参考值 |
| --- | --- |
| 组原点 | 舞台 left `6%`、top `3.5%` |
| 切换器盒子 | 位于组原点的 `5.1cqw` 正方形，视觉 Y 为 `-.95cqw` |
| 品牌起点 | 切换器右边缘 + `.8cqw` |
| 品牌宽度 | `31cqw` 参考盒 |
| 工具栏起点 | 相对组原点 X `+12.5cqw`、相对舞台高度 Y `+8%` |
| 工具栏终点 | 舞台右侧内缩 `2.5%` |

当前实现把等价位置编码为舞台 left `18.5%`、top `11.5%`。新文档和未来令牌工作 MUST 从上述 Brand 关系定义该位置，而不是把它视为无关的视口锚点。

整个 Header Composition Group MAY 为响应式构图整体移动。除非批准例外修改具体关系，其子项 MUST 保持相对几何。

## 5. Standard Atlas 几何参考

Deep Sea 提供以下经过验证的空间关系，但不提供其艺术皮肤：

| 系统 | `standard-atlas` 参考 |
| --- | --- |
| 品牌模式 | 切换器旁的左对齐运行时标题/副标题 |
| 地图视口 | 等比 `scale(.94)`，Y 平移 `1.2cqw`，中心原点 |
| 运行时地图变换 | 共享等比 zoom 层加共享国家聚焦 scope 层；主题皮肤不得改变其数学 |
| 缩放控件 | left `7.2%`、top `26%`、width `3.55cqw`、aspect `1/3` |
| 参考工具栈 | left `7.2%`；top `60%` 加 `-2cqw` 视觉偏移 |
| 图例 | width `13cqw`、aspect `4/3` |
| 地图细节 | width `12.5cqw`，位于图例下方，栈间距 `.16cqw` |
| Timeline | 第 3 节的共享 Timeline v2 值 |
| 打开后的明信片 | top `6%`、right `0`、width `23.5%`、aspect `3/4`、家族 scale `1.5`、原点 top-right |

全部七个开放主题使用共享舞台、Atlas/Globe 几何和 Timeline v2 构图，并通过主题作用域做视觉校正。禁用的计划主题只有在实现另行获批后才获得几何家族。

## 6. 几何分类

共享/冻结示例：

- 舞台比例、地图投影、组件职责、工具栏顺序、语义盒、最小点击区、时间线行为和排版字号角色。
- 工具栏与品牌的关系；Atlas zoom/国家 scope 行为，以及地图/材质/标记变换耦合。

几何家族示例：

- 左对齐与居中品牌构图。
- 地图内缩、左侧工具栈位置、时间线原型、明信片外部构图和响应式重排。
- 第 5 节中 Deep Sea 为 `standard-atlas` 提供的值。

主题皮肤示例：

- 颜色、材质、纹理、图像、字体家族、发光、阴影、边线处理、标记艺术和装饰轮廓。
- 清单记录的栅格 `contain`/`cover`/`fill`、裁切和仅艺术层缩放。

## 7. 校正与重设计

主题 MAY 使用小幅视觉偏移来校正透明边距、不规则轮廓或字体度量，但 MUST NOT 改变功能边界或同级关系。

以下情况需要例外：

- 功能锚点相对继承值移动超过 `.6cqw`，或功能尺寸改变超过 `5%`。
- 重排组、改变工具栏基线、拆分 Header Composition Group，或直接相对视口定位工具栏。
- 切换明信片方向、改变信息顺序、把图例/细节系统移到另一侧，或在共享国家聚焦变换之外添加主题专用非等比地图缩放。
- 添加未继承或未批准的地图框、面板、边线、阴影盒或装饰性地图容器。

当清单证明功能边界不变时，仅艺术层的裁切/缩放 MAY 超出这些阈值。

## 8. 响应式几何

响应式行为 SHOULD 让几何家族整体适配，不要在多个断点上独立散布组件覆盖。在完整移动端家族获批前，保留当前行为、报告限制，并且不要声称移动端已完全一致。
