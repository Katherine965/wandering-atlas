# Travel 明信片构图

本文是供人工评审的中文同步版本，英文 [../06-postcard-composition.md](../06-postcard-composition.md) 为规范文本。

## 1. 共享明信片契约

明信片行为和信息层级是共享的。艺术 MAY 大幅变化，但主题 MUST 继承所选几何家族构图和共享排版角色，除非存在已批准的结构例外。

共享行为包括选择与关闭、照片排序与选择、竖图处理、标签页、图注、笔记、详情、元数据、剪贴簿/画廊、灯箱、键盘导航和页面滚动锁定。

## 2. 信息层级

运行时层级 MUST 保持为：

1. 地点身份：标题以及国家/地区/类型眉题。
2. 分区导航：Photos、Notes、Details。
3. 主照片。
4. 缩略图选择。
5. 图注、笔记或详情内容。
6. 日期、评分和地点元数据。
7. 可选的档案/剪贴簿入口。

视觉顺序 MAY 仅通过已批准的明信片几何变体调整。数据与交互逻辑 MUST 保持共享。

## 3. Standard Atlas 明信片参考

Deep Sea 明信片提供首个 Standard Atlas 竖版构图。下列值相对未缩放明信片盒；该家族从右上角原点统一应用 `1.5` 外部缩放。

| 角色 | 参考几何 |
| --- | --- |
| 外部卡片 | top `6%`、right `0`、舞台 width `23.5%`、aspect `3/4` |
| 关闭控件 | top `13.8%`、right `12%`、卡片 width `5.3%` |
| 眉题 | top `16.8%`、left `18%`、width `64%` |
| 地点标题 | top `18.7%`、left `18%`、width `64%` |
| 标签页 | top `23.1%`、left `17%`、width `66%`、height `3.8%` |
| 主照片 | top `28%`、left `17%`、width `66%`、height `25%` |
| 缩略图 | top `55.2%`、left `17%`、width `66%`、height `7.4%` |
| 图注/内容 | top `65%`、left `17%`、width `66%`、height `8.5%` |
| 元数据 | top `75.2%`、left `17%`、width `66%`、height `11.5%` |

这些值定义层级与对齐。其他框架的已审计安全区 MAY 需要受限内缩校正，但仅凭这一点 MUST NOT 建立新的信息层级。

## 4. 框架与安全区

实现前，清单 MUST 记录：

- 外部画布和可见艺术边界。
- 透明开口与内容安全矩形。
- 照片开口、装饰重叠和永久印刷艺术区域。
- 关闭控件安全区。
- 允许的适配与拉伸行为。

栅格边界 MUST NOT 自动成为卡片功能边界。运行时内部区域 SHOULD 基于已审计安全区定位，同时保留继承的信息层级。

## 5. 排版

明信片标题、眉题、标签页、图注、元数据标签和元数据值 MUST 使用 [03 排版](../03-typography.md) 中的共享角色。主题 MAY 改变字体家族、颜色、材质、效果、字形、字距和允许的视觉缩放。

MUST NOT 仅为适配装饰边距而缩小文字。如果批准框架无法以可读字号容纳继承层级，应声明结构例外或拒绝该资产承担此角色。

## 6. 照片与运行时内容

- 横向照片 SHOULD 使用共享裁切行为。
- 竖向照片 SHOULD 使用配置的 contain/backdrop 处理。
- 缩略图 MUST 保持可选择，并由共享状态排序。
- 地点名、日期、评分、位置、图注、笔记、标签和选中照片 MUST 保持为运行时内容。
- MUST NOT 使用城市专属艺术作为通用明信片外壳。
- 永久装饰印刷文字只有在不与语言或运行时数据冲突时 MAY 保留在框架中。

## 7. 结构变体

横向卡片、纵向缩略图轨道、隐藏可见标签页、重排元数据或分离档案控件都属于结构变体，而不是皮肤。实现前 MUST 将其声明为几何例外或具名可复用明信片家族。

一个现有主题专属分支不能证明新增分支合理。可复用表现需求 SHOULD 变成类型化 variant 或 slot。

## 8. 验证

在匹配桌面与窄视口下，验证较长的英文/中文标题、无照片状态、横竖照片、最大缩略图数量、所有标签页、长图注/笔记/标签、缺失元数据、关闭点击区、画廊/灯箱入口和框架重叠。
