# Travel 环境行为

本文是供人工评审的中文同步版本，英文 [../07-ambient-behavior.md](../07-ambient-behavior.md) 为规范文本。

## 1. 范围

环境表现是可选主题皮肤。它 MUST NOT 承载 Travel 产品语义、替代缺失结构资产，或成为理解/操作页面的必要条件。

环境表现可以是被动效果，也可以是拥有独立表现状态的隔离角色。

## 2. 共享约束

- 环境层 MUST 不阻挡交互、对辅助技术隐藏，并在适用时使用 `pointer-events: none`。
- 环境内容 MUST NOT 移动、缩放、遮挡共享控件，或成为共享控件的点击目标。
- 环境状态 MUST 与条目、标记、明信片、Timeline、语言、Owner Edit、持久化、API 和存储分离。
- 动效 MUST 遵守 `prefers-reduced-motion`；直接移除是可接受回退。
- Timer、observer、RAF callback 和异步路线 MUST 在卸载时清理。

## 3. 当前只读版本

当前五个主题不包含独立 ambient actor；没有对应组件或帧资源需要加载。保留这些隔离/逐帧资源规则用于另行批准的未来装饰工作；不得据此创建新功能。

## 4. 资产与架构规则

- 在有序类型化数组中，每个动画帧使用一张图片；不要把当前序列替换为合成 sprite sheet。
- 帧动画 MUST 与世界移动和朝向分离。
- 装饰路径点 MAY 从现有表面测量，但 MUST NOT 重定义这些表面的几何。
- 不连续路线 MAY 使用隐藏/再出现过渡。
- 未来第二个环境角色 SHOULD 使用可复用类型化挂载/配置，而不是增加另一个主题 ID 分支。

## 5. 验证

验证点击穿透、层级、帧顺序、图片加载、路线边界、尺寸变化、隐藏/显示过渡、CPU 使用、减少动态效果、小舞台抑制和清理。环境功能失败时，Travel 界面 MUST 保持完全可用。
