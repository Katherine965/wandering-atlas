Definitions, registry and shared presentation types live under `app/travel/themes/`. Images live under `public/travel/themes/<id>/`. Theme selection persists locally. Only these five themes are registered; no extra/experimental asset trees are included.

Active art bytes were preserved. Deep Sea download-named resources use neutral role filenames; references were changed only in this standalone copy. Repeated image roles may share one image. Original extension/actual format mismatches are retained for non-sensitive paths to minimize changes; the built server detects PNG payloads.

The owner generally confirms that most five-theme images were made using OpenAI image generation. This does not identify each file. `ASSET_PROVENANCE.csv` therefore holds individual assets for owner classification: original AI-generated (OpenAI), AI-generated with third-party reference, third-party, or unknown. Confirmed original AI assets need no invented stock-image license; referenced/third-party/unknown art still requires review. No theme was regenerated or visually standardized.

Browser rendering is not proved by source/build checks. See validation evidence and remaining browser/fixed-camera gates.
