# Wandering Atlas v1.0.0

The first open-source release of Wandering Atlas: a personal travel archive with an interactive Globe and world map.

- Five visual themes: Parchment, Fairy Tale, Cyber, Deep Sea and Ice World.
- Journey and Location entries, markers, timeline, postcards and photo archive.
- Independent local editing with photo uploads, cover selection and file-based persistence; no cloud account required.
- Mobile Globe layout with three primary actions and a three-year timeline.
- English README with real browser screenshots and retained geographic, font and dependency credits.

Requires Node.js 22.13+ and npm. Run `npm ci` and `npm run dev:local` to edit your own archive; `npm run dev` opens the fictional read-only demo.

Original code uses MIT. Theme imagery and third-party materials follow ASSETS.md and THIRD_PARTY_NOTICES.md. Private archives, credentials, caches and native dependency binaries are excluded. Automated archive import/restore is not part of v1.0.
